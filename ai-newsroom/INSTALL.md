## 📥 સ્ટેપ 1 — Python ઈન્સ્ટોલ કરો

1. બ્રાઉઝરમાં ખોલો: **https://www.python.org/downloads/**
2. મોટું પીળું બટન **"Download Python 3.12.x"** દબાવો
3. ડાઉનલોડ થયેલી ફાઈલ (`python-3.12.x-amd64.exe`) ડબલ-ક્લિક કરો
4. ⭐ **સૌથી અગત્યનું:** પહેલી સ્ક્રીનમાં નીચે
   **"Add python.exe to PATH"** નું ✅ ટિક **ફરજિયાત** કરો
5. **"Install Now"** દબાવો → પૂરું થાય એટલે **Close**

**ચેક કરો:** Start મેનૂમાં `cmd` લખી **Command Prompt** ખોલો, એમાં લખો:
```
python --version
```
`Python 3.12.x` દેખાય તો ✅ પાસ. ન દેખાય તો Python ફરી ઈન્સ્ટોલ કરો અને
PATH વાળું ટિક ચૂક્યા નથી ને એ જુઓ.

## 📥 સ્ટેપ 2 — સોફ્ટવેર ડાઉનલોડ કરો

**રીત A — ZIP થી (સહેલી):**
1. બ્રાઉઝરમાં તમારું GitHub repo ખોલો:
   `https://github.com/akshaykananidwk/Public-daily-India`
2. લીલું **"< > Code"** બટન → **"Download ZIP"**
3. ડાઉનલોડ થયેલી ZIP ફાઈલ પર જમણું-ક્લિક → **"Extract All..."**
4. અંદરથી **`ai-newsroom`** ફોલ્ડર કોપી કરીને `C:\` માં મૂકો
   → એટલે ફોલ્ડર બનશે: **`C:\ai-newsroom`**

**રીત B — Git થી (અપડેટ સહેલા રહે):**
1. https://git-scm.com/download/win પરથી Git ઈન્સ્ટોલ કરો (બધે Next દબાવો)
2. Command Prompt માં:
```
cd C:\
git clone https://github.com/akshaykananidwk/Public-daily-India.git
```
3. પછી `C:\Public-daily-India\ai-newsroom` એ જ તમારું ફોલ્ડર.

> આગળના બધા સ્ટેપમાં હું `C:\ai-newsroom` લખીશ — તમારું ફોલ્ડર બીજે હોય
> તો એ રસ્તો વાપરજો.

## 📥 સ્ટેપ 3 — સોફ્ટવેરની જરૂરી લાઈબ્રેરી ઈન્સ્ટોલ કરો

Command Prompt ખોલીને **એક પછી એક** આ લખો (દરેક લાઈન પછી Enter):

```
cd C:\ai-newsroom
pip install -r requirements.txt
```

2-3 મિનિટ ચાલશે. છેલ્લે `Successfully installed ...` આવવું જોઈએ.

પછી પોસ્ટર બનાવવા માટેનું Chromium (એક જ વાર):

```
playwright install chromium
```

આ ~150 MB ડાઉનલોડ કરશે.

> ❌ `pip is not recognized` આવે તો → સ્ટેપ 1 નું PATH ટિક ચૂકી ગયા છો.
> Python ફરી ઈન્સ્ટોલ કરો.

## 🤖 સ્ટેપ 6 — Ollama ઈન્સ્ટોલ કરો (AI ખરેખર ન્યુઝ લખે એ માટે)

> આ સ્ટેપ વગર સોફ્ટવેર "ડેમો મોડ" માં ચાલે છે. GPU નબળું હોય તો આ સ્ટેપ
> પછી માટે રાખી શકો.

1. **https://ollama.com/download** ખોલો → **Download for Windows**
2. ડાઉનલોડ થયેલી ફાઈલ ચલાવો, Install દબાવો
3. Command Prompt ખોલીને મોડેલ ડાઉનલોડ કરો:

```
ollama pull gemma3:12b
```
(~8 GB ડાઉનલોડ — ઈન્ટરનેટ પ્રમાણે 15-60 મિનિટ)

24 GB VRAM વાળું GPU હોય તો વધુ સારું મોડેલ પણ:
```
ollama pull gemma3:27b
```

4. સોફ્ટવેરમાં **⚙️ સેટિંગ** ટેબ → **AI (Ollama)** વિભાગ:
   - 12 GB GPU હોય તો: લેખન મોડેલ = `gemma3:12b`
   - 24 GB GPU હોય તો: લેખન મોડેલ = `gemma3:27b` (ડિફોલ્ટ)
   - **સેવ કરો** દબાવો
5. સોફ્ટવેર બંધ કરી ફરી ચાલુ કરો → ડાબી નીચે **"Ollama ચાલુ"** લીલું દેખાશે ✅

**AI ટેસ્ટ:** ડેશબોર્ડમાં **"🚀 દિવસ શરૂ કરો"** દબાવો — સ્કાઉટ સાચા ન્યુઝ
લાવશે અને AI ગુજરાતીમાં લખશે. પહેલા 20 ન્યુઝની જોડણી ધ્યાનથી તપાસો!

## 📤 સ્ટેપ 8 — Facebook પબ્લિશિંગ જોડો (વૈકલ્પિક)

ટોકન વગર સોફ્ટવેર "સિમ્યુલેશન મોડ" માં પબ્લિશ કરે છે (કંઈ ખરેખર પોસ્ટ થતું નથી).
ખરેખર પોસ્ટ કરવા:

1. https://developers.facebook.com પર જાઓ → Facebook એકાઉન્ટથી લોગિન
2. **My Apps** → **Create App** → પ્રકાર: **Business**
3. તમારી App માં **Facebook Login** + **Pages API** ઉમેરો
4. **Graph API Explorer** ટૂલમાં જઈ તમારા Page માટે
   **Page Access Token** બનાવો (permissions: `pages_manage_posts`,
   `pages_read_engagement`)
5. તમારા Facebook Page ની Settings માં નીચે **Page ID** મળશે
6. સોફ્ટવેરના **સેટિંગ → પબ્લિશિંગ** માં બંને નાખો → સેવ કરો

> ⚠️ લાંબા ગાળાનો (long-lived) ટોકન બનાવવો — સાદો ટોકન 1-2 કલાકમાં
> એક્સપાયર થાય છે. Meta Business Verification હોય તો ટોકન 60 દિવસ+ ચાલે.
