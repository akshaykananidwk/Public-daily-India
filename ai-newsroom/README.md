# AI Newsroom — Public Day India (Python વર્ઝન)

માસ્ટર પ્લાન v2.0 નું Python અમલીકરણ. Electron ને બદલે Python સર્વર +
બ્રાઉઝર UI — ડબલ-ક્લિકે એપ ખૂલે, બધું તમારા કોમ્પ્યુટરમાં લોકલ ચાલે.

## શું શું છે

- 👑 **9 એજન્ટ** — CEO, સ્કાઉટ, લેખક, શુદ્ધિ, ડિઝાઈનર, ફોટો, પબ્લિશર, જવાબ, એનાલિસ્ટ
- 📺 **લાઈવ એનિમેટેડ ડેશબોર્ડ** — કયો એજન્ટ શું કરે છે એ આંખે દેખાય, CEO કામ વહેંચે ત્યારે લાઈન પર ટપકું દોડે
- 🖼️ **પોસ્ટર એન્જિન** — Chromium (Playwright) થી HD પોસ્ટર, ગુજરાતી અક્ષર તૂટે નહીં (3 સાઈઝ: પોસ્ટ / પોર્ટ્રેટ / સ્ટોરી)
- 🤖 **Local LLM** — Ollama (gemma3) + બે-પગલાંનું ગુજરાતી લેખન (અંગ્રેજી ડ્રાફ્ટ → અનુવાદ → પોલિશ). Ollama બંધ હોય તો ડેમો મોડ — સિસ્ટમ અટકતી નથી
- 🟠 **અપ્રુવલ સ્ક્રીન** — તમારી મંજૂરી પછી જ પબ્લિશ થાય
- 📊 **રિપોર્ટ** — રોજ/મહિનાના આંકડા, એજન્ટ પરફોર્મન્સ
- 🔄 **GitHub One-Click અપડેટ** — બેકઅપ → ડાઉનલોડ → માઈગ્રેશન → હેલ્થ ચેક, ભૂલ પડે તો ઓટો રોલબેક
- ⏰ **ઓટો રન** — રોજ સવારે (સેટિંગમાં સમય નક્કી કરો)

> 📘 **સ્ટેપ-બાય-સ્ટેપ ઈન્સ્ટોલ ગાઈડ (ગુજરાતીમાં, શરૂઆતથી):**

## ઈન્સ્ટોલ (Windows / Linux / Mac)

```bash
# 1. Python 3.11+ જોઈએ
pip install -r requirements.txt

# 2. પોસ્ટર માટે Chromium (એક જ વાર)
playwright install chromium

# 3. (વૈકલ્પિક પણ ભલામણ) Ollama — https://ollama.com પરથી ઈન્સ્ટોલ કરી:
ollama pull gemma3:12b
ollama pull gemma3:27b     # 24GB VRAM હોય તો

# 4. ચલાવો
python run.py              # Windows પર start.bat ડબલ-ક્લિક પણ ચાલે
```

બ્રાઉઝર આપોઆપ ખૂલશે → `http://127.0.0.1:4700`

## વાપરવાની રીત

1. **🚀 દિવસ શરૂ કરો** — સ્કાઉટ RSS માંથી ન્યુઝ લાવે → CEO પસંદ કરે →
   લેખક લખે → શુદ્ધિ તપાસે → ડિઝાઈનર 3 સાઈઝમાં પોસ્ટર બનાવે →
   અપ્રુવલ ટેબમાં આવે
2. **પ્રેસ નોટ** — ડેશબોર્ડમાં લખાણ પેસ્ટ કરો → એક ન્યુઝ + પોસ્ટર બને
3. **🟠 અપ્રુવલ** — પોસ્ટર જોઈ ✅ મંજૂર (પબ્લિશ થાય) કે ❌ રદ કરો
4. **⚙️ સેટિંગ** — મોડેલ, RSS ફીડ, Facebook ટોકન, GitHub અપડેટ

## ફોલ્ડર

```
ai-newsroom/
├── run.py, start.bat          # એન્ટ્રી પોઈન્ટ
├── newsroom/                  # 🔄 એન્જિન (અપડેટ થાય)
├── templates/                 # 🔄 પોસ્ટર ટેમ્પ્લેટ (ગુજરાતી CSS નિયમો સાથે)
├── web/                       # 🔄 ડેશબોર્ડ UI

├── config/                    # 🔒 સેટિંગ
```
